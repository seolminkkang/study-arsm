# output — 공개용 글

`raw/`, `experiments/`, `concepts/`에서 파생된 글.

## 공개 원칙

**책 요약을 올리지 않는다.** 목차를 옮기고 각 절을 요약하면
사실상 책의 대체재가 되어 저작권 문제가 된다.

공개하는 것은 **"책이 말한 걸 실제로 재봤다"**로 한정한다.
- (X) "3장 2절 요약"
- (O) "인덱스 컬럼 순서를 바꿔봤더니 실행계획이 이렇게 달라졌다"

후자가 저작권 문제도 없고 포트폴리오 가치도 높다.
책은 출처로 한 줄 언급하면 된다.
