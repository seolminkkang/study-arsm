# raw — 측정 원본

**이 폴더의 파일은 수정하지 않는다.**

원본을 고치면 그때 실제로 무엇이 측정됐는지 확인할 방법이 사라진다.
해석이 바뀌면 `experiments/`의 노트를 고치고 여기는 그대로 둔다.

## 파일명

```
YYYY-MM-DD_exp-NNN_설명.txt
2026-09-06_exp-001_k6-offset-99990.txt
2026-09-06_exp-001_explain-before-index.txt
```

같은 실험을 다시 돌렸으면 기존 파일을 덮어쓰지 말고 새 파일을 추가한다.
언제 무엇이 달라졌는지가 그 자체로 정보다.

## 넣을 것
- k6 요약 출력 전문
- `EXPLAIN ANALYZE` 결과 전문
- Grafana 캡처
- 에러 로그

## 넣지 않을 것
- 해석, 요약, 결론 → `experiments/`
- 대용량 덤프 → gitignore

## 리허설 / 당일 구분

조건이 다르다. 리허설은 한 대 + 100 rps, 당일은 두 대 + full load
(`lab/README.md` "부하 생성기 위치" 참고). 절대값이 다르므로 섞이면
둘 다 못 믿는 숫자가 된다.

파일명에 `rehearsal` / `session`을 반드시 넣는다.
```
2026-09-03_exp-001_rehearsal_k6.txt
2026-09-06_exp-001_session_k6.txt
```

실험 노트도 따로 만든다. `exp-001-rehearsal`과 `exp-001`은 별개 노트다.
리허설 노트를 나중에 당일 노트로 고쳐 쓰지 않는다.

리허설 노트의 결론(conclusion)에는 **성능 수치를 쓰지 않는다.**
판정(성공/애매/실패)만 적는다 — 한 대에서 나온 절대값은 당일 두 대
결과와 비교 대상이 아니라서, 수치를 적어두면 나중에 헷갈려서 잘못
인용하게 된다.
