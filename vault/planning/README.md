# planning — 회차 전에 만든다

**다음 회차를 준비할 때 여기부터 본다.**

회차당 세 개를 만든다.

| 파일 | 역할 |
|---|---|
| `NNN-plan.md` | 계획. 실험 명세, 조건, 판정 기준, **왜 이렇게 하는지** |
| `NNN-cheatsheet.md` | 당일 실행. 그대로 치는 명령어와 던질 질문만. 설명 없음 |
| `NNN-overview.html` | 같이 보는 슬라이드. 회차 시작 5분간 띄운다 |

개관을 `.md`로 따로 만들지 않는다. 슬라이드와 내용이 겹친다.
슬라이드의 원문은 `NNN-plan.md`의 "회차 시작 5분 — 같이 보는 것" 절에 둔다.

Challenger에게 미리 보내는 사전 공지(`NNN-brief.md`)가 필요하면 여기 같이 둔다.
**결과나 힌트를 담지 않는다** — 관찰하고 예측하는 게 회차의 핵심이라
미리 알면 그 과정이 통째로 사라진다.

회차가 끝난 뒤에 쓰는 기록은 `sessions/` 쪽이다.
