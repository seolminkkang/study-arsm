# planning — 회차 전에 만든다

**다음 회차를 준비할 때 여기부터 본다.**

회차당 세 개를 만든다.

| 파일 | 역할 |
|---|---|
| `NNN-plan.md` | 계획. 실험 명세, 조건, 판정 기준, **왜 이렇게 하는지** |
| `NNN-cheatsheet.md` | 당일 실행. 그대로 치는 명령어와 던질 질문만. 설명 없음 |
| `NNN-overview.html` | 같이 보는 슬라이드. 회차 시작 5분간 띄운다. 브라우저로 열고 방향키로 넘긴다 — `n` 키를 누르면 발표자 노트가 보인다 |

개관을 `.md`로 따로 만들지 않는다. 슬라이드와 내용이 겹친다.
슬라이드의 원문은 `NNN-plan.md`의 "회차 시작 5분 — 같이 보는 것" 절에 둔다.

**회차당 이 세 개만 만든다.** Challenger에게 미리 보낼 내용은 파일로 만들지 않는다 —
필요하면 `NNN-plan.md`의 실험 조건 부분을 그대로 복사해서 보낸다.
단, **결과와 힌트는 빼고** 조건만 보낸다. 관찰하고 예측하는 게 회차의 핵심이라
미리 알면 그 과정이 통째로 사라진다.

회차가 끝난 뒤에 쓰는 기록은 `sessions/` 쪽이다.
