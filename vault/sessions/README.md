# sessions — 회차 후에 쓴다

**이번에 뭘 했고 뭘 틀렸는지.**

파일명은 `YYYY-MM-DD-N회차.md`다. 회차당 하나.

`_template.md`의 항목을 따른다.

- 오늘 한 것
- 관찰 단계에서 나온 "이상한 점"
- **예측이 틀린 지점** — 맞은 건 적지 않는다. 틀린 것만
- 다룬 등급 (A / B / 넘김 `#미실험`)
- 다음 회차로 넘기는 질문

넘긴 절은 사유(`시간부족` / `재현위험` / `환경없음` / `뒷장재등장`)와 함께
[[progress]]에도 남긴다.

회차 전에 만드는 준비물(계획·커닝페이퍼·슬라이드)은 [[planning]] 쪽이다.
