# 4·5장 실습 — 실행 안내

학습 교재는 [textbook/index.html](textbook/index.html)을 브라우저로 열어 읽으세요.
저장소를 내려받은 뒤 파일을 더블클릭하면 됩니다. GitHub에서는 코드로 보일 수 있습니다.
교재의 인터랙션은 개념 설명용이며, 아래 실습 페이지는 실제 로컬 서버·DB를 사용합니다.

리뷰·포인트 서비스로 외부 연동 장애와 개선을 비교하는 로컬 실습입니다.
배치·CDC는 별도 실습 테이블을 사용합니다. 전체 순서와 의미는 [CURRICULUM.md](CURRICULUM.md)를 참고하세요.

## 1. 실행자 한 명만 서버 켜기

준비물: Docker Desktop(실행 상태), Python 3, 내려받은 이 저장소.
최초 빌드는 인터넷 연결이 필요합니다. Java는 컨테이너 안에서 빌드합니다.

터미널에서 **저장소의 `lab/integration` 폴더로 이동한 뒤** 실행하세요.

```sh
docker compose up --build -d
python3 scripts/session.py serve
```

두 번째 명령이 실행된 터미널은 열어 둡니다. 서비스가 준비될 때까지 잠시 기다린 뒤
실행자 브라우저에서 <http://127.0.0.1:8090>을 엽니다.
이미 화면 서버가 실행 중이면 명령을 또 실행하지 말고 주소만 여세요.

## 2. 친구와 두 화면으로 진행

- 두 노트북을 같은 신뢰할 수 있는 사설 Wi-Fi에 연결합니다.
- 실행자 페이지의 **친구 접속 주소**를 친구에게 전달합니다.
- 친구는 자기 브라우저에서 그 주소를 엽니다. 친구 컴퓨터의 `localhost`로 접속하는 것이 아닙니다.
- 설명 → 두 사람의 예측 → 실행 버튼 → 실제 결과 → 해설 순서로 진행합니다.
- 코드 블록은 읽기용입니다. 실험 도중 터미널에 코드를 입력할 필요가 없습니다.
- Grafana는 선택 사항입니다. 실행자 컴퓨터의 <http://127.0.0.1:3001>에서 볼 수 있습니다.

관찰용 포트는 8091입니다. 접속이 안 되면 같은 Wi-Fi인지, 호스트 방화벽이나
공유기의 기기 간 통신 차단이 있는지 확인하세요. 인터넷 배포나 포트포워딩은 하지 마세요.
실행자 노트북이 잠들거나 네트워크가 바뀌면 연결이 끊길 수 있습니다.

## 3. 다시 접속하거나 종료하기

- 탭만 닫았으면 실행자 주소를 다시 열면 됩니다.
- 화면 서버가 꺼졌으면 이 폴더에서 `python3 scripts/session.py serve`를 다시 실행합니다.
  **새 세션으로 시작하며 이전 화면 기록을 자동 복원하지 않습니다.** DB 데이터와 파일 기록은 남습니다.
- Docker 서비스가 꺼졌으면 `docker compose up -d`로 다시 켭니다.
- 종료 전 기록을 내려받고 **마무리 단계**를 실행하세요. 특히 CDC는 재개/마무리로 슬롯을 정리한 뒤 종료하세요.
- 화면 서버 터미널에서 `Ctrl+C`로 종료합니다. 컨테이너도 멈추려면 같은 폴더에서:

```sh
docker compose stop
```

## 데이터 보호

이 환경은 `arsm-integration` 전용 환경입니다. 기존 영화 실습 DB를 변경하지 않습니다.
단, 반복 실험 데이터는 이 환경 안에 계속 남습니다. **새 세션 시작은 DB 초기화가 아닙니다.**

처음부터 다시 실험하려면 페이지 하단 **이번 실험 초기화**의 삭제 범위를 읽고 진행하세요.
이 기능은 백업 후 전용 8개 테이블을 비웁니다. 배치 파일·이전 기록·백업은 남습니다.
미완료 CDC 슬롯 등이 있으면 안전을 위해 초기화를 거절합니다.
`docker compose down -v` 등으로 볼륨을 삭제하지 마세요.

상세 설정과 문제 해결은 [README.md](README.md)를 참고하세요.
